# E-Commerce Customer Behavior & Sales Analysis Using SQL

## 📌 Project Overview

This project analyzes e-commerce customer behavior and sales data using MySQL. The goal is to answer real-world business questions related to sales performance, customer behavior, product categories, payment methods, and customer spending.

The project uses SQL queries to transform raw e-commerce data into meaningful business insights.

## 🎯 Objectives

* Analyze overall sales performance
* Identify high-value customers
* Compare product categories
* Analyze payment methods
* Understand customer purchasing behavior
* Calculate important business metrics
* Practice SQL concepts using a real-world dataset

## 📊 Dataset

The dataset contains 5,000 e-commerce transactions with information related to customers, products, purchases, payments, devices, sessions, delivery, and customer ratings.

## 💡 Business Questions

Some of the questions explored in this project include:

1. What is the total revenue generated?
2. What is the average order value?
3. Which product categories generate the most revenue?
4. Who are the top 10 highest-spending customers?
5. Which payment methods generate the most revenue?
6. Which cities generate the most revenue?
7. How does customer behavior differ between returning and non-returning customers?
8. Does delivery time have a relationship with customer ratings?
9. Which orders have unusually high transaction values?
10. Do customers using different devices show different purchasing behavior?

## 🚀 Learning Outcome

This project helped me strengthen my understanding of SQL by applying database concepts to realistic business problems rather than practicing isolated SQL queries.

Future improvements will include advanced SQL concepts such as CTEs, CASE statements, and window functions, followed by visualization using Power BI.
